# NDDC Connect 🌐

### Self-Service Hostel Wi-Fi & ISP Automation Platform

NDDC Connect is a digital Wi-Fi management platform designed to simplify hostel internet access through automated plan selection, payments, user accounts, and network access management.

## 🚀 Features

- 📋 Wi-Fi plan selection
- 👤 User account management
- 💳 Online payment integration
- 🤖 Telegram bot interface
- 📊 Usage management
- 🔐 Device management architecture
- 🌐 Captive portal interface
- ⚡ Automated payment verification
- 📡 MikroTik integration architecture

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Python
- SQLite
- Telegram Bot API
- Paystack API
- REST APIs
- Webhooks
- MikroTik
